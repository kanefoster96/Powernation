# Image guide

Every image slot is now filled. Slots without a real photo yet show a blurred uniform image with an **"Image coming soon"** label, so the site looks complete.

**To see which file each slot expects**, add `?slots` to any page address (e.g. `/shop.html?slots`). Drop a file at that path and it replaces the "coming soon" image automatically.

**Filled from your photos:** heroes, shoe feature, uniform tiers, both galleries, the home banner, upgrades (rhinestones, mesh, printed designs), process and Roster Refill images, practice wear and backpack tiles, Club Shop and About images, club logos (Starlets, Sapphire, Airscorps, Liberty, ACA, Bomb Squad), 8 colour tiles, and products: Power Crop Top, Practice Shorts, Rhinestone Practice Tee, Racerback Tank, Nfinity Backpack, black Nfinity shoe.

**Still "coming soon"** (listed below): bows, hoodies and warm-ups, accessories, floors, the HQ photo, metallic/embroidery/bow upgrades, teal/navy/gold colour tiles, and the remaining products.

- Use **.jpg** for photos (export at the size shown, around 80% quality) and **.png** for logos.
- Keep faces and key action in the top two-thirds of hero and banner images; text sits over the bottom third.
